# Bright Data 浏览器 API Python Selenium 项目

[![Bright Data 推广](https://github.com/bright-cn/Awesome-Web-Scraping/raw/main/Proxies%20and%20scrapers%20GitHub%20bonus%20banner%20CN.png)](https://www.bright.cn/)

<a href="https://codesandbox.io/p/devbox/github/bright-cn/bright-data-browser-api-python-selenium-project?file=%2Findex.py" target="_blank" rel="noopener">在 CodeSandbox 中打开</a>，使用 GitHub 账号登录，然后复刻此存储库即可开始修改。

本项目演示如何使用 <a href="https://www.bright.cn/products/scraping-browser" target="_blank" rel="noopener">Bright Data 浏览器 API</a>，通过 Python 和 Selenium 从网站抓取数据。

### 快速入门

1. 在 `index.py` 中，将 `YOUR_BRIGHT_DATA_BROWSER_API_ENDPOINT` 替换为你实际的 Bright Data 浏览器 API HTTP 端点
2. 将 `"https://example.com"` 替换为你的目标 URL
3. 运行 `pip install -r requirements.txt` 安装依赖项
4. 运行 `python index.py` 开始抓取
